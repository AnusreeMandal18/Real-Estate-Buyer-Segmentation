# 🏠 Machine Learning Based Buyer Segmentation and Investment Profiling for Real Estate Market Intelligence

## 📌 Project Overview

This project applies Machine Learning techniques to segment real estate buyers based on their investment behaviour and demographic characteristics. The objective is to help real estate organizations understand different buyer profiles and support data-driven marketing and investment strategies.

The project includes data preprocessing, feature engineering, exploratory data analysis, buyer segmentation using K-Means clustering, cluster validation, and investment profiling.

---

## 🎯 Objectives

- Clean and preprocess client and property datasets.
- Engineer meaningful investment-related features.
- Perform Exploratory Data Analysis (EDA).
- Segment buyers using Machine Learning.
- Profile each buyer segment.
- Support business decision-making through customer intelligence.

---

## 📂 Dataset

The project utilizes two primary datasets:

- Clients Dataset
- Properties Dataset

These datasets were integrated to generate a comprehensive buyer intelligence dataset for analysis and machine learning.
